# Repository change

Use this skill for requested code or configuration changes.

1. Read applicable repository instructions before editing.
2. Inspect the smallest relevant area first.
3. Make the narrowest change that satisfies the request.
4. Do not commit, push, change remotes, or access credentials.
5. Run the most relevant repository-native validation available for the changed area.
6. Report what changed, validation performed, and any unresolved limitation.
